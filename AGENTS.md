# Проверка изменений дизайна

По просьбе владельца сначала передавайте отдельную Windows-сборку локальным
файлом для просмотра любых изменений дизайна. Общий релиз и обновление рабочего
сайта с этим дизайном выполняйте только после его явного одобрения.

Для TRLKA не использовать skill unslop и не следовать его рекомендациям,
если владелец явно не попросит об этом снова. Предпочтение владельца —
сохранять прежний яркий дизайн сайта; редизайн приложения сейчас не нужен.
