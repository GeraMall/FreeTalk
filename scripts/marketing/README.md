# TRLKA — локальный демонстрационный стенд и ролик

Стенд импортирует настоящие `AccountSidebar`, `FriendsPage`, `ChatsPage` и
`RoomView`. Стили продукта не перерисованы для рекламы. Данные вымышленные:
Сергей, Аня, Макс и Даша. Аватары — оригинальные SVG-иллюстрации; демонстрируемый
маршрут рисуется локально на canvas и передаётся в настоящий видеокомпонент
через `captureStream`. Это постановочная демонстрация интерфейса, не тест
сетевого звонка, задержки связи или качества звука.

## Изоляция

- Отдельный вход `apps/desktop/marketing/index.html`; основной `main.tsx` его
  не импортирует. Проверка DEV и localhost запрещает запуск опубликованной копии.
- API и realtime заменены локальными заглушками до монтирования компонентов.
- Во время записи Playwright дополнительно запрещает внешние HTTP и WebSocket.
- Настоящие аккаунты, токены, контакты и сообщения не используются.
- Модуль стенда и демонстрационные строки отсутствуют в production bundle.

## Пересъёмка

Из корня репозитория запустить в двух терминалах:

```powershell
pnpm --filter @freetalk/desktop exec vite --host 127.0.0.1 --port 1440 --configLoader runner
python -m http.server 1442 --bind 127.0.0.1 --directory design/landing
```

Затем открыть сессию и записать материалы:

```powershell
npx --yes --package @playwright/cli playwright-cli -s=marketing open http://127.0.0.1:1440/marketing/
node scripts/marketing/run.mjs record
node scripts/marketing/run.mjs invite
python scripts/marketing/render.py --ffmpeg C:/path/to/ffmpeg.exe
node scripts/marketing/run.mjs verify
```

Для рендера нужны Pillow и numpy. Шрифты берутся из Windows (`Segoe UI`).
Путь ffmpeg по умолчанию — локальная установка imageio-ffmpeg в
`output/media-tools`; можно передать другой через `--ffmpeg`.
`run.mjs` подставляет текущий корень вместо пути машины автора и адаптирует
отформатированную JS-функцию под `playwright-cli run-code`.

Выходные файлы:

- `output/marketing/TRLKA-demo-1080p.mp4`: ролик 1920×1080, 28,85 секунды.
- `design/landing/assets/demo/trlka-tour.mp4`: облегчённый H.264/AAC 1280×720.
- `design/landing/assets/demo/*.webp`: снимки и обрезанные фрагменты реального UI.
- `output/playwright/marketing-*-result.json`: результаты съёмки и проверок.

Музыка синтезирована скриптом рендера; чужие записи и видеоматериалы не использованы.
Титры встроены в видео, также доступна русская дорожка VTT. Видео на сайте не
загружается до нажатия кнопки, останавливается при закрытии окна; фокус возвращается
на кнопку запуска. Вход ведёт на существующую публичную веб-версию приложения.

## Проверенные размеры и сопутствующие исправления

Главная: 320, 390, 820, 1024, 1280, 1920 px. Проверены загрузка изображений,
отсутствие горизонтального переполнения, открытие/закрытие видео и возврат фокуса.

Настоящие компоненты друзей, чатов, звонка и демонстрации: 820, 900, 1024, 1280,
1366, 1920 px. Дополнительно звонки с 1, 2, 4 и 8 участниками. Горизонтальная
лента участников демонстрации остаётся прокручиваемой внутри своей области;
страницу она не растягивает.

- `ChatLayoutPreview`: для друзей удалён режим чата, обнулявший внешние отступы.
  Основной `HomeView` уже выбирал этот режим правильно.
- `styles.css`: у одного/двух аудиоучастников убрана жёсткая минимальная ширина
  280 px. На окне 820 px две карточки раньше выходили за область на 22 px.
- `RoomView`: подписка на native `call-popout-restored` выполняется только в Tauri;
  браузер больше не выбрасывает ошибку `transformCallback` при открытии звонка.

Это проверка отображения в браузере, не проверка на физическом iPhone/iPad.
Публичный сайт, серверы и каналы обновлений не менялись. Сначала локальный просмотр.
