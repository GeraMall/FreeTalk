# Проверка мобильного сайта TRLKA — 1 ноября 2026

## Найденные причины и исправления

- Главная при viewport 390 px имела scrollWidth 648 px. Абсолютные декоративные орбиты расширяли корневую область прокрутки. Ограничена геометрия декора и горизонтальное переполнение html/body, сохранена нативная вертикальная прокрутка. Существующий яркий дизайн взят с рабочего сайта, без unslop.
- В шапке на 320–400 px уменьшены только промежутки, чтобы логотип, вход и меню помещались в одну строку.
- На планшете specificity старого правила chat-direct сохраняла дополнительную колонку профиля и сжимала переписку. До 1100 px профиль изначально свёрнут, по кнопке открывается поверх переписки. Смена размера закрывает панель, не меняя текущий чат.
- Веб-клиент удалял refresh token при любой ошибке восстановления входа. Теперь сеть/5xx сохраняют его, включая токен после успешной ротации. Только 401/403 очищают отвергнутую сессию.
- Зависшее восстановление ограничено 15 секундами; есть явная повторная попытка и восстановление по событию online. Обработчик подключается до показа ошибки, чтобы не терять ранний online в WebKit. Событие online при здоровом входе не перемонтирует приложение и звонок.

## Проверено

- Chromium и WebKit: главная, меню и вертикальная прокрутка при ширинах 320, 360, 390, 430, 768, 820, 1024, 1366, 1920 px. scrollWidth совпадает с clientWidth; горизонтальная позиция остаётся 0.
- Оба движка: главная аккаунта, список из 28 чатов, переписка из 120 сообщений с длинной ссылкой, друзья, история и настройки при 320, 390, 430, 768, 820, 1024 px.
- Открытие/возврат/повторное открытие чата, прокрутка списка и сообщений, открытие настроек одним нажатием, восстановление после смоделированного 503.
- Chromium: нативный синтетический жест пальцем с диагональным движением прокручивает список по вертикали и не уводит документ вбок.
- Планшет: ширина переписки не меньше 400 px; открытие профиля не уменьшает её.
- Сборка TypeScript + Vite; 303 теста веб-клиента, включая новые регрессии восстановления входа и мобильного online/retry.
- Рабочий API beta.38, signaling 0.1.5 и Caddy отвечали на момент проверки; NRestarts=0. На диске свободно 5.6 ГБ, доступная память около 430 МБ, swap не использовался.

## Пределы проверки

UI-проход выполнен с изолированными тестовыми данными и перехваченными API/WebSocket-запросами. Чужие аккаунты и переписки не использовались; тестовые данные не входят в production build. Проверка не равна нагрузочному тесту или длительному звонку на реальном iPhone. Фоновое поведение iOS зависит от Safari/системы; такой прогон не подтверждает непрерывную работу при блокировке телефона. Внешние технические работы провайдера одним исправлением клиента не устраняются.

Скриншоты, сценарии CLI и машинные отчёты: `output/playwright/` локального checkout. Production bundle исключает sourcemaps. При установке сохраняются предыдущие assets и резервные HTML для отката; службы звонков не перезапускаются.
