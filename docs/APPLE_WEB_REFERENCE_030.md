# TRLKA iPhone 0.3.0 build 10 — ориентир: мобильный веб

Перенесено оформление существующих экранов входа, главной, чатов, друзей,
истории, настроек и редактирования профиля. Добавлены официальный чат бота
с командами/поиском/профилем и профиль собеседника/список участников группы.
Серверные лимиты обращений используются через те же API, что и веб.

`WebTheme.swift` хранит отдельные токены для экранов вне звонка:
холст `#07111d`, входящие `#101e2e`, исходящие `#1a2c48`, ввод `#050d18`,
заголовок `#0a1623`, граница `#29384e`. Старые глобальные токены Brand,
Panel и ProfileAvatar сохранены, поскольку ими пользуется экран звонка.

- Аватар и плашка выровнены сверху; свои сообщения справа, чужие слева.
- Текст сообщения 14pt, время 10pt, аватар 32pt; компактные плашки с отступом
  10×12pt и углами 14pt. Длинный текст переносится; ширина ограничена геометрией экрана.
- Ввод 16pt, кнопка отправки 44×44pt со скруглением 12pt; поддержан многострочный текст.
- Нижняя навигация скрыта в открытом чате и при клавиатуре, возвращается после выхода.
- SwiftUI safe areas определяют положение заголовков/ввода, без фиксированных
  ручных отступов, завязанных на модель iPhone.
- Корневые экраны используют общую плотность, цвета и линейные системные иконки.
- Настройки — компактное меню разделов; обложка и редактирование находятся
  внутри «Профиль». Раздел «Чаты» сохраняет масштаб текста сообщений,
  «Устройства» показывает текущий системный аудиомаршрут.
- Бот — специальный пункт навигации, не обычный пользователь. Поиск и история
  используют только авторизованные `/v1/service-chat/messages`; UUID отправки
  сохраняется для повтора после сетевой ошибки. Подписка не включает платежи.

Файлы `CallScreen.swift`, `CallController.swift`, `VideoCallCanvas.swift`,
`WaitingPersonCard.swift`, `BrandComponents.swift`, `TRLKAApp.swift` не изменены.
Входящий оверлей AppShell сохраняет прежний Panel. Показ/сворачивание звонка
работают через прежний контроллер; это изменение не добавляет фоновый VoIP/APNs.

Дизайн не добавляет кнопки без работающего действия: перенос внешнего вида
не означает, что все возможности Windows/web уже реализованы в native.
В частности, нативные вложения/GIF и регистрация остаются отдельной функциональной задачей.

Основной веб-эталон — ветка `preview/chat-alignment-182`:
`apps/desktop/src/chat-theme.css`, `components/service-chat.css` и
`docs/MOBILE_CHAT_ALIGNMENT_182.md`. Эти правила можно повторно использовать для Android.
