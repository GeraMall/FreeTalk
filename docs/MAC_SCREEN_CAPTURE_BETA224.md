# Mac: размер захвата и профиль по умолчанию

08.11.2026. Подготовка тестовой beta.224; публичная версия остаётся223.

Владелец подтвердил плохое изображение сразу после запуска, в том числе
Text/30FPS. Первый присланный FreeTalk-diagnostics-1788031296.json относится
к beta.37 от29августа и не содержит демонстрации. Актуальный файл
Trlka-diagnostics-1794161679.json: beta.223, исходники32893df1390b,
создан2026-11-08T18:14:39.697Z. Все707 screen-quality:sample содержат
capture640×414 и outbound640×414. Режимtext, adaptivefalse, level0;
почти всегда30FPS, H264, qualityLimitationReason none. Доступный битрейт
в последних замерах~8.29Мбит/с; отдельные потери пакетов встречаются,
поэтому нельзя утверждать, что сеть идеальна. Захват уже низкого разрешения:
изменение только maxBitrate этого не исправляет. Стартовые события вытеснены
из ограниченного буфера, исходные capabilities в223 не записывались.

После выбора источника на Mac отдельно применяются ограничения размера
к самому MediaStreamTrack до публикации. Целевой размер учитывает выбранное
разрешение, возможности источника и его пропорции; маленькое реальное окно
не растягивается искусственно. Width-only exact допускается после выбора,
при отказе — мягкий запрос ширины. Каждая попытка ограничена2.5секундами;
после таймаута вторая операция не ставится за потенциально зависшей первой.
Отказ настройки не уничтожает работавшую трансляцию. Windows/камера прежние.
В диагностике теперь есть результат настройки и в периодических замерах
добавлены максимальные размеры источника и выбранные разрешение/FPS.

Основание способа настройки:
[пояснение разработчика WebKit](https://bugs.webkit.org/show_bug.cgi?id=250200),
[правила ограничений существующего трека](https://www.w3.org/TR/screen-capture/).
Это обоснованная правка по локальному логу, а не подтверждение физическим Mac.
Повторный чёрный старт и отсутствие системного звука не объявлять исправленными.

Новый профиль Mac по умолчанию: text/1080p/30FPS, адаптация включена;
прежний default-off системного звука сохранён. Явные настройки не перезаписываются.
В настройках Mac есть кнопка применения профиля, переведённая на все7языков.
Windows сохраняет balanced/1080p/30FPS. Контрольные проверки настроек/видео
и отказов/таймаута прошли; последний целевой запуск63теста.

Нативный пакет224 пока не собран и не опубликован. Сначала отдельный preview,
проверка на устройстве друга, затем решение владельца об общем выпуске.
