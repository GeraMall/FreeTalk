# Предпросмотр beta.195: статус после сворачивания

Дата: 05.11.2026. Публичная версия остаётся beta.194.

## Причина и исправление

Нижняя панель держала отдельный локальный статус своего realtime-соединения.
Его закрытие сразу переводило индикатор в offline, хотя другие подписки аккаунта
могли оставаться подключёнными. Панель также начинала с offline при новом
монтировании. Возврат фокуса не ускорял ожидающее переподключение.

- Статус своего аккаунта теперь общий для всех подписок текущего входа. Отказ одной подписки не означает отключение всего аккаунта; приоритет статусов совпадает с серверным.
- Панель получает текущий снимок статуса при создании вместо начального ложного offline.
- Если оборвались все подписки, предусмотрено окно восстановления до трёх секунд. При длительном обрыве индикатор действительно становится offline. Последний выход из аккаунта переводит его в offline сразу; снимок и таймер удаляются.
- Фокус, pageshow и возвращение видимости сразу запускают ожидающее переподключение. Исправление не пересоздаёт здоровое соединение и не дублирует одновременно выполняемую авторизацию.
- Сообщение presence отправляется только после server ready. Раньше изменение статуса во время незавершённой авторизации могло нарушить порядок протокола и привести к закрытию сокета сервером.
- Правило пяти минут без действий/речи и ручные статусы сохранены.

## Проверки

- В установленной Windows beta.194 воспроизведён переход: сразу после восстановления окна доступное имя индикатора «Не в сети», затем «В сети».
- 403 frontend-теста, включая 29 проверок realtime, общего состояния статуса и панели — успешно.
- ESLint, TypeScript и сборка Windows NSIS — успешно.
- В браузере с настоящим компонентом панели и управляемым тестовым WebSocket проверены закрытие одной подписки, краткое закрытие всех, полный обрыв и восстановление. Ложных переходов в offline при кратком восстановлении: 0; отправок presence до авторизации: 0. При полном обрыве offline появляется после ограниченного ожидания, затем online восстанавливается.
- Проверка исправленной нативной сборки с двумя реальными устройствами ещё не выполнена; автоматические и браузерные проверки её не заменяют.

Локальный файл: `outputs/Trlka_0.4.0-beta.195_presence-preview_x64-setup.exe`.
Публикация beta.195 и изменение серверных служб не выполнялись.
