# TRLKA beta.197

Владелец разрешил общий выпуск 05.11.2026 после проверки локальной Windows beta.197.
Платформы: Windows x64, macOS Apple Silicon и веб-приложение.

- Исправлено исчезновение интерфейса текущего звонка и нарушение переключения чатов из-за повторных ключей React.
- Повторное подключение больше не отправляет старые SDP/ICE до подтверждения входа в комнату. Убраны циклы ошибок «Сначала войдите в комнату», ограничено ожидание и число повторов.
- Выход отменяет незавершённое подключение. Запоздалые ответы микрофона, авторизации и прежнего звонка не меняют новый звонок.
- Исправлены краткие ложные состояния «Не в сети» при восстановлении окна и переподключении аккаунта.
- Возврат в чат текущего звонка сразу показывает его панель, без промежуточного кадра обычного чата и повторной анимации появления.

Проверка: `pnpm check`, 609 тестов; полный App в браузере, 90 кадров возврата на трёх размерах окна; передача аудио между двумя настоящими локальными WebRTC-клиентами и восстановление после переподключения. Владелец подтвердил работу исправлений beta.196 и одобрил общий выпуск beta.197.

Нативные iOS/Android и Mac Intel в этот выпуск не входят. Код API и сервера сигналинга не меняется; статическое обновление веба не требует прерывания звонков.
