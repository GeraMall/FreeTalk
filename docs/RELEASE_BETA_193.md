# TRLKA beta.193

Владелец разрешил общий выпуск 05.11.2026 после локального Windows-предпросмотра.

- Во время звонка ЛС кнопка участников недоступна; в группах она работает.
- Реакции звонка вынесены поверх переписки и карточек, включая полный экран.
- В Windows-выборе демонстрации можно отключить звук. Начальное значение включено.
- Миниатюры источников загружаются параллельно с ограничением в две задачи и коротким локальным кэшем.
- Выключение наушников выключает микрофон; включение микрофона возвращает звук. Состояние передаётся собеседникам.
- Обновлены переводы предпросмотров, статусов друзей, служебных сообщений и документов; пользовательский текст не переводится.
- Включены исправления профиля, настроек, подсказок и тёмного фона входа из проверенного предпросмотра.
- Объединены исправления геометрии звонка и демонстрации Mac из ветки macOS preview. Выпускается только Apple Silicon.

Номер 193 выше частных Mac-предпросмотров 190–192. Магазин и активности остаются закрыты для обычных аккаунтов. Еды в навигации нет.

Проверки: общий `pnpm check`, сборка и подпись автообновления Windows/macOS в CI, проверка публичных артефактов перед переключением релиза. Реальная аппаратная проверка Mac у получателя остаётся необходимой: CI не подтверждает звонок на его ноутбуке.
