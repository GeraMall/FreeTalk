# Windows-preview beta.216

08.11.2026. Ветка `preview/tablet-chat-beta216`, исходники `492e209`.
Приватный Windows-preview после beta.215. Публичный клиент/сайт/фид остаются
beta.205. Общий выпуск этой версии владелец ещё не запрашивал.

## Монополия: более долгий бросок

Бросок новой версии длится 2200 мс вместо 900. Увеличены разлёт, вращение,
высота начального подскока; уменьшено трение, ориентация доводится плавно
в последние 550 мс. Два кубика при встряхивании вращаются по-разному.
Направление и скорость отпускания участвуют в общем детерминированном броске,
а бросок кнопкой получает вариацию из серверных чисел и последовательности.
Сервер по-прежнему определяет числа и экономику, клиент считает только визуал.
Звуки shake/roll оригинальные, пересозданы под жест и окно 2,2 секунды.
Прежнее прекращение звука при отмене/выходе/остановке сохранено.

Новое время согласуется флагом `propertyRoll:2` и необязательным
`lastMove.rollMs`. Старый клиент инициирует прежний бросок 900 мс;
новый клиент понимает оба времени. Путь фишки начинается после соответствующего
времени броска, шаг по-прежнему 110 мс. Старые столы и финансовые правила
не меняются. Для совместной проверки нового визуала всем нужен beta.216.
Используется 2,5D-модель, не полноценный движок трёхмерных твёрдых тел.

## Звонок и прокрутка

До первого отображения комнаты состояние сразу переводится в «Подключение…».
Ранее оно могло оставаться `offline`, пока начинались асинхронные операции
микрофона/авторизации, что показывало ложный красный индикатор.
Настоящие последующие ошибки соединения продолжают отображаться.

В чате не записывается повторно уже достигнутая нижняя позиция. Используется
реальный максимум `scrollHeight-clientHeight`, а не заведомо избыточная высота.
На нижней границе исключена конкуренция браузерного якоря с ручным удержанием;
при чтении старых сообщений якорь сохраняется. Переполнение не прокручивает
родительскую область. Проверка колеса на конце чата: 25 прокруток, смещение
последнего сообщения 0 px. Это локальная проверка отображения, не гарантия
отсутствия всех возможных причин редкого подёргивания в живом звонке.

## Избранное и настройки

Активный флажок избранного получает мягкую жёлтую заливку и обводку.
После «Профиль» добавлен раздел «Интерфейс» с иконкой панелей. Выбор языка
перенесён туда из «Чаты», в самом верху. Перезапуск при смене языка прежний.
Под сбросом настроек добавлен выход из аккаунта; сброс располагается выше.
Новые основные подписи переведены на все шесть дополнительных языков.

## Чат комнаты: фото и файлы

Фон, шапка, аватарки и панель ввода приведены к общим поверхностям чата.
Можно выбрать фото/файл, перетащить файл или вставить изображение из буфера,
добавить подпись. Повторная отправка во время загрузки блокируется, ошибка
сохраняет черновик для повтора. Фото открывается поверх приложения,
файл скачивается с исходным именем. Размер показывается в подходящих единицах.

Файлы идут отдельным HTTP-запросом, не через WebSocket звонка. У каждого
подключённого участника отдельный случайный токен только этой сессии;
загрузка и чтение требуют текущего членства. Отправитель не может приписать
себе чужой файл, другая комната не может его прочитать. Произвольные внешние
URL не принимаются. Токен не попадает в URL, постоянное хранилище или журнал.

Хранилище временное, в памяти: до 10 МиБ на файл, 32 МиБ на комнату,
128 МиБ глобально с учётом текущих загрузок, до 200 файлов комнаты / 2000 всего.
Есть ограничение частоты и таймаут загрузки. После ухода последнего участника
данные удаляются при очистке, не позднее 30 секунд. HTTP-кеширование запрещено.
Неподдерживаемые типы скачиваются как `application/octet-stream`, не исполняются.
В HA-перенос файлов/историю они не входят, как и сам временный чат комнаты.

## Меню чатов

Правый клик/Shift+F10: закрепление/открепление, выключение/включение
уведомлений, архив, удаление личного чата, блокировка собеседника.
Для группы удаляющее действие подписано «Покинуть группу», блокировки группы
нет. Удаление/выход/блокировка используют существующее подтверждение и API,
действие не выполняется просто от выбора пункта меню.

Закрепление поднимает чат над остальными, маленькие иконки обозначают закрепление
и выключенные уведомления. Личные mute/pin сохраняются в `chat_members`
через новый `/preferences`, сообщаются только самому аккаунту.
Уведомления архива и выключенного чата подавляются в desktop-overlay,
звуках и серверных Web/Android push-очередях; счётчики непрочитанных сохраняются.
Миграция `029_chat_preferences.sql` добавляет nullable-поля без изменения
данных остальных участников. Пользовательские сообщения не удаляет.
