# TRLKA beta.201

Владелец явно разрешил публикацию 06.11.2026: исправить доступ всех участников к планшету, восстановление чата и размеры приглашения, затем выпустить для всех. Windows x64, macOS Apple Silicon и веб; Intel Mac и мобильные пакеты не входят.

## Исправления

- Убрана оставшаяся клиентская проверка `canAccessStore` при передаче состояния активности в звонок. Обычные зарегистрированные аккаунты получают приглашение и могут открывать и управлять общим планшетом. Доступ к магазину не меняется.
- Планшет временно скрывает чат, сохраняя выбранное пользователем состояние отдельно. После сворачивания, завершения активности другим участником или выхода из звонка временное скрытие снимается. Открытый ранее чат возвращается, скрытый остаётся скрытым.
- Приглашение использует геометрию аудиокарточек либо видеокарточек в зависимости от режима звонка. На узком экране содержимое видеоприглашения компактно размещается внутри карточки.

## Проверки

- Регрессионная проверка App: состояние активности приходит обычному аккаунту с `canAccessStore=false`, управление отправляется через signaling, временное скрытие не меняет выбор чата.
- RoomView: приглашение, присоединение, сворачивание инициатором и гостем, завершение с другого клиента, повторное открытие и очистка при размонтировании.
- Браузерная проверка 32 сочетаний: аудио/камера, открытый/скрытый чат, обычный/Mac layout, 1366×900, 1065×650, 800×600, 390×750. Размеры приглашения совпадают с карточкой участника; содержимое не выходит за рамки.

- `pnpm check` прошёл: форматирование, lint, типы, 640 тестов и production-сборки. Один отдельный предварительный запуск обнаружил нестабильный тест HomeView; его повторная адресная проверка и полная проверка затем прошли без изменений этого кода.
- На двух временных аккаунтах с `canAccessStore=false` проверен полный интерфейс production-сборки через рабочие API и signaling: оба запускают планшет, присоединение по приглашению, общий ход e2–e4, сворачивание, завершение с другого клиента, возврат открытого чата и сохранение скрытого. В браузерной проверке использован искусственный аудиотрек; физические микрофоны и запуск на физическом Mac в этой сессии не проверялись. Временные аккаунты и тестовый чат удалены.
- Веб опубликован с резервной копией `/var/backups/trlka-beta201-app-20261106T150526Z`; рабочие звонки и серверные процессы не перезапускались. Публичный экран входа без ошибок JavaScript и горизонтальной прокрутки.
