# TRLKA 0.4.0-beta.181

Владелец разрешил общий выпуск после просмотра Windows preview beta.181.
Интерфейс соответствует проверенной сборке из `38da0ef`.

- Официальный чат бота TRLKA: уведомления об ожидании звонка, обращения об ошибках,
  предложения, профиль и поиск по собственной истории.
- Предложения `/idea` и `/feedback` — одно за 24 часа на аккаунт.
- Пять минут первоначального ожидания без собеседника вместо восьми;
  участников состоявшегося разговора за AFK не отключает.
- Единый тёмный фон и оформление сообщений в личных, групповых чатах и чате комнаты.
- Белый заголовок бота слева, выровненные по высоте поле ввода и кнопки,
  исправление высоты обычного мобильного чата.
- Подписка пока информационная, платежи не включены.

API beta.42 уже работает; почта поддержки `trlkacom@mail.ru`.
Проверки и сведения о серверной части:
`CHAT_SURFACES_PREVIEW_181.md`, `SERVICE_BOT_PREVIEW_2026-11-02.md`.

Для общего выпуска Windows собирается штатным подписанным workflow;
preview-установщик не используется как подписанное автообновление.
