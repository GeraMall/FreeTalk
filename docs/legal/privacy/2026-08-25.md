# Политика конфиденциальности FreeTalk

Версия: `2026-08-25`

Статус: проект для закрытого beta-тестирования. Это не обещание защиты от любых юридических рисков.

Для аккаунта обрабатываются email, username, display name, avatar, session/security metadata, друзья, членство в чатах и история факта звонков. Текст сообщений удаляется после установленного срока. Аудио, видео и содержимое экрана не передаются account API и не используются для аналитики. Пароли хранятся только как Argon2id hash; session tokens — только в виде server-side SHA-256 hash с секретным pepper.
