# TRLKA 0.4.0-beta.179

- Основные кнопки приложения используют палитру сайта: мягкий стальной синий
  переходит в яркий синий. Единый градиент применяется к созданию комнаты,
  подтверждениям, настройкам, профилю, приглашениям и отправке сообщений.
- Верхняя и боковая панели имеют общий сплошной фон; удалены разделительная
  линия и старый светлый блик. Скругление выполнено со стороны рабочей области.
- Исправлены отступы экрана друзей и ширина карточек аудиозвонка в узких окнах.
- В браузере звонок больше не пытается подписаться на нативное событие окна.
- Зелёные, жёлтые и красные индикаторы сохраняют своё значение.

Владелец разрешил общий выпуск после отдельного Windows-предпросмотра.
Изменения интерфейса совпадают с проверенной сборкой; номер повышен до beta.179
для доставки через обычное обновление. Серверная логика/API в этот выпуск не входит.
