# TRLKA beta.204

Опубликована 7 ноября 2026 после одобрения владельцем Windows-предпросмотра.

- Клиент: `c659552`, ветка `release/video-covers-beta204`, тег `v0.4.0-beta.204`.
- [Общий выпуск](https://github.com/GeraMall/FreeTalk/releases/tag/v0.4.0-beta.204).
- [Успешные сборки Windows и macOS](https://github.com/GeraMall/FreeTalk/actions/runs/42383961532).
- Платформы: Windows x64, macOS Apple Silicon, веб. Mac Intel не собирался.

## Изменения

Обложки YouTube, Rutube и VK Видео расположены под текстом ссылки. Добавлены
YouTube Live, резервная загрузка доверенных изображений и компактный вид при
недоступной обложке. VK получает метаданные через официальный открытый oEmbed
с запросом 1280×720, без исполнения полученного HTML.

Архив и Избранное добавлены рядом с плюсиком в обычной AccountSidebar.
Основное меню и внешний вид левой панели сохранены. Изолированный тестовый
ChatsPage без AccountSidebar не является дизайном основной программы.
Избранное — личный чат заметок, архивирование доступно через контекстное меню
и не изменяет список собеседника. Сохранены исправления и резервные endpoints beta.203.

## Проверки и развёртывание

GitHub Actions завершил общие проверки, Windows-сборку и macOS ARM-сборку с
проверкой `/usr/lib/swift` LC_RPATH. Подписи установщика Windows и архива
macOS проверены локально по открытому ключу обновлений TRLKA. Публичный
`releases/latest/download/latest.json` соответствует проверенному manifest,
оба установочных пакета доступны с ожидаемым размером.

На контролируемых временных аккаунтах проверены повторное открытие одного
Избранного, пустая начальная история, сохранение заметки, запрет доступа
другому участнику, личное архивирование и совместимость старого списка чатов.
Проверены авторизованные метаданные и изображения Rutube/VK; YouTube имеет
прямую резервную обложку. Временные аккаунты и чаты удалены.

API beta.50 получил только обновление модуля link-preview при отсутствии
активных комнат; сигналинг не перезапускался. Веб-файлы опубликованы с
сохранением прежних хешированных assets. Основной узел — Москва, резерв —
Петербург; синхронная репликация и оба контроллера исправны. Установщики
раздаются GitHub Releases и не дублируются на малом диске резерва.
