# TRLKA Android 0.3.0-preview.1

Ориентир — iPhone 0.3.0 build 10. Нативный Android-клиент использует Kotlin и Compose. Идентификатор `io.freetalk.mobile` сохранён, код версии повышен до 18.

- Вход, главная, список чатов, друзья, история и настройки используют общую палитру `MobileDesign`. Системные панели и клавиатура учитываются через Compose Insets.
- В переписке аватары выровнены по верхнему краю, время находится внутри плашки. Размер текста и зеркальность локальной камеры сохраняются на устройстве.
- Чат TRLKA использует действующий API служебных сообщений. Поиск, профиль и команды доступны в отдельном экране. Повтор отправки сохраняет идентификатор запроса.
- В звонке четыре основные кнопки. Дополнительные действия собраны в «Ещё». При сворачивании экран скрывается, а подключение и сервис звонка сохраняются. Видеоплитки делят доступную площадь по тому же алгоритму, что iPhone.

Сборка для установки — `output/android-preview/TRLKA-0.3.0-preview.1.apk`. Android 10 и новее. Подпись отладочная. APK проверен `apksigner`, SHA-256 `6da42ea5f2feed9ef63b899ffa191ab6759153a0bbf4263eaf82623c21b76669`.

Проверены 19 модульных тестов и 4 сценария на эмуляторе Android 15. Тесты интерфейса используют локальные данные. Живой звонок с микрофоном, камерой и демонстрацией экрана требует проверки на устройствах.
