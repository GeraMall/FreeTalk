# Windows/web preview beta.181

По запросу владельца — отдельная Windows-сборка до общего выпуска интерфейса.

- Заголовок «На связи — TRLKA» белый; приветствие и история выровнены слева.
- Официальный профиль бота открывается из заголовка/кнопки справа. На ПК это
  боковая панель; на планшете и телефоне — закрываемое наложение.
- Поиск по сообщениям бота выполняется сервером только в истории текущего
  аккаунта, включая сообщения вне последних открытых 100 записей. Подстрока
  параметризована; запрос ограничен 200 символами, результат — последними 100 совпадениями.
- `/idea` и `/feedback`: максимум одно предложение за скользящие 24 часа.
  Проверка серверная и защищена от параллельных отправок; повтор принятого UUID
  остаётся идемпотентным. Общий лимит 5 обращений/24 часа сохраняется;
  сообщение об ошибке можно отправить отдельно от предложения.
- Фон `#07111d`, входящие `#101e2e`, исходящие `#1a2c48` применены к обычным
  личным/групповым чатам и чату комнаты. Пользовательские обои и масштаб текста сохранены.
  Изображения/GIF/приглашения сохраняют собственное оформление карточек.
- Подсказка под строкой ввода бота удалена. Поле и кнопка отправки — 60px на ПК,
  как профиль слева; на телефоне — 44px. В обычном чате кнопки файла/GIF
  также выровнены по высоте. Вложения, ответы и многострочный ввод сохранены.
- Исправлена лишняя строка мобильной сетки, из-за которой обычный чат занимал
  только часть высоты экрана и оставлял пустое место под полем ввода.

## Проверки

Полный `pnpm check`: форматирование, lint, типы, тесты и сборки пакетов пройдены.
API — 121 тест, клиент — 325 тестов. Проверки браузером: 1366×900, 820×1180,
390×844; профиль бота открывается/закрывается, поиск и очистка поиска работают,
горизонтального переполнения и ошибок JavaScript нет. На ПК профиль, поле и
отправка высотой 60px, расхождение по вертикальному положению около 1px;
на телефоне ввод и отправка 44px. Для сценариев UI использованы тестовые аккаунты
и сообщения, без действий с реальными пользователями.

Физические устройства и живые звонки не проверялись в рамках визуального изменения.
Отключения за AFK в разговорах не добавлялись; пять минут остаются только для
первоначального вызова без подключившихся собеседников.
