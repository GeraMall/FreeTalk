# Windows-preview beta.214

08.11.2026. Ветка `preview/monopoly-motion-beta214`, исходники `fb359da` (основная анимация `c2ee6bf`).
Частный Windows-preview после beta.213. Публичные сайт, клиенты и фид
по-прежнему beta.205; общего выпуска владелец ещё не разрешал.

## Покер: плавная реакция аватаров

Прежняя плашка могла резко исчезнуть, когда следующий игрок действовал:
все аватары зависели от единственного `lastAction`. Теперь у каждого места
сохраняется его последняя реакция, и она независимо завершает затухание.
При новой раздаче/другом столе старая реакция не показывается.

Цвет и текст плавно появляются/исчезают за 2,2 секунды без масштабирования
аватарки. Текст входит с небольшим смещением на 2 px. Поздний снимок начинает
анимацию с уже прошедшего времени; обычное обновление ставки её не перезапускает.
Кольцо таймера, кнопки решений и звуки покера сохранены.

## Монополия: поле и движение

Клетки получили собственные локальные SVG-рисунки: зелёная стрелка старта,
оранжевая тюрьма с решёткой, красная машина стоянки, паровозы у вокзалов,
капля водостанции, молния энергостанции, карточки шанса/события и сборов.
Используются единый рисунок и цветовая палитра; внешних загрузок картинок нет.
Все участки названы улицами Москвы; в синей группе — Тверская и Арбат.
На поле показана основная часть названия, в карточке/портфеле/обмене — полная форма.
По последнему уточнению владельца у всех улиц один размер и умеренная жирность 700. Размер выбирается сразу для всего поля по результату измерения 22 названий,
включая загрузку шрифта и изменение размеров. Переносы предусмотрены заранее,
индивидуальных гигантских заголовков и обрезки букв нет. В очень тесных клетках
цена доступна в карточке, освобождая место под подпись.

Названия — клиентское отображение прежних индексов. Цены, цветовые группы,
аренда, залог, дома/отели и серверные правила beta.213 остаются прежними.
Индекс используется одинаково на поле, в портфеле, карточке и обмене.
Точные старые названия в серверном журнале подменяются при отображении.
Подпись раздела — «Улицы Москвы».

Отдельная маленькая рамка для кубиков убрана. Зажатую пару можно перетаскивать
по всему зелёному центру мышью/пальцем. После отпускания локальная сцена
учитывает скорость жеста, отскоки от краёв, равномассовое столкновение двух
кубиков, высоту подпрыгивания и трение. Расчёт ограничен шагами 1/120 секунды;
при задержке кадра объём догоняющей работы ограничен. Дальше ориентация плавно
доводится до результата сервера в существующее окно 900 мс.
Это простая локальная 2,5D-модель для CSS-кубиков, не полноценный движок твёрдых тел.
Положение после жеста локально; авторитетные числа кубиков общие для стола.

Кубики и тени двигаются через transform без перерисовки всего React-поля
на каждый кадр. При выходе из игры кадры и наблюдение размера отменяются.
Учитываются уменьшение движения, отмена жеста, второй палец, изменение размера,
клавиатура и серверная блокировка повторного броска.
Звуки столкновений используют существующий ограничитель частоты/громкости.

Фишка проходит клетки короткими подпрыгиваниями с затухающим следом на клетке.
Координаты и моменты шага берутся из прежнего серверного пути. Таймер состояния
во время движения обновляется через 25 мс вместо 80 мс; серверных сообщений
на каждый кадр нет. Подсветка купленной карточки при наведении светло-серая.

## Проверки

Полный `pnpm check` завершился успешно: формат, lint, типы, тесты и сборки.
Журнал `outputs/doc-review/monopoly214-check.log`: desktop 500, protocol 131
(включая dist-копии тестов), signaling 41, API 145, Cloudflare 15, admin 2.
В одном параллельном проходе единично не прошёл прежний тест HomeView
«restores a recent chat instantly». Отдельный повтор HomeView дал 22/22;
повтор полного pnpm check завершён успешно, desktop 500/500. Код чатов
в этой версии не менялся. Исходный журнал сохранён как
`outputs/doc-review/monopoly214-check-first.log`.

Тесты проверяют столкновение кубиков, границы на трёх размерах, конечные грани,
неизменность цены/группы, независимые реакции аватаров и их устойчивость
при повторном снимке. Существующие проверки правил/покера beta.213 проходят.

Браузер: 1488×1111, 1240×1000, 1040×800, 800×800, 390×1024,
390×844, 320×847 и 320×667. Лобби, стол, модальные карточки/обмен/победа
помещаются в планшет без вертикального скролла. При жесте мышью зафиксирован
перенос кубика на 180 px по X и −65 px по Y; при броске все проверенные
границы кубиков остаются внутри зелёного поля. Проверены touch с двумя пальцами,
однократная отправка броска, звуки, волны/подпрыгивания при последовательных шагах.
Реакция аватарки в браузере проходит opacity от нуля до единицы и обратно,
её размер и transform остаются постоянными. Артефакты `output/playwright/mono214-*`
и `output/playwright/poker214-feedback-*`. Дополнительно проверены все 22 московские карточки на четырёх размерах: названия
не выходят за клетки, размер един для всего поля; модальные карточки без скролла.
При экстремально малом планшете подписи неизбежно малы, полные названия доступны
при нажатии на клетку. Журнал `output/playwright/mono214-moscow-report.txt`.
Физические телефоны не тестировались.
