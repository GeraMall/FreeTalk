## Выделение и пересылка

Кнопка «Поделиться» находится между копированием и снятием выделения, работает
для одного и нескольких сообщений. Пересылка последовательная, в порядке
сообщений исходного чата. Синхронный guard исключает повторную отправку двойным
нажатием. После частичного успеха остаются выделены только неотправленные
сообщения, их можно повторить; уже подтверждённые сообщения не повторяются.
При переходе в другой чат оставшаяся очередь прекращается после текущего запроса.
Существующий API пересылки текста/медиа/авторства сохранён, сервер не менялся.

Пустое место в строке перед галочкой переключает выделение одним кликом.
Текст, ссылки, фото, кнопки и карточки звонков сохраняют свои действия.
Drag/range и подавление завершающего click, Escape и доступная клавиатурная
галочка сохранены. По последнему уточнению владельца новая область полностью
невидимая: нет подложки выбранной строки и её hover-тени в режиме выделения.
Обычные наведения вне выделения не менялись.

В окне пересылки «Избранное» первое, обычные чаты по `lastMessageAt` от новых
к старым, служебный TRLKA последний. Текущий чат исключён как прежде;
поиск сохраняет этот порядок, исходный список чатов не мутируется.
Подписи новых действий переведены на все семь языков интерфейса.

## Стабильность профиля и уведомления бота

`presence-updated` больше не повышает глобальную ревизию профиля.
Статус берётся из актуального участника чата без повторного HTTP-запроса.
Для уже загруженного профиля повторное обновление идёт поверх прежних данных:
аватар, обложка и описание не заменяются skeleton, при ошибке остаются видимы.
Кэш ограничен сессией компонента и разделён ключом viewer/target; ответ другого
профиля не показывается. Первое открытие допускает первоначальную загрузку.
Полный профиль тоже не запрашивается заново при смене только presence.
Снимок видимой переписки сохраняется до следующей отрисовки навигации,
что устраняет гонку мгновенного возврата в чат под нагрузкой.

Счётчик AccountSidebar теперь принимает системные уведомления служебного бота
с `sender_id: null`; прежде фильтр пропускал только пользовательские сообщения.
Свои команды не считаются непрочитанными. Возврат к боту сбрасывает индикатор.
HomeView различает видимый служебный чат и тот же запомненный chatId при открытом
разделе «Главная»/«Друзья». Счётчики двух слоёв объединяются прежним `max`,
без удвоения. Изменения БД или формата realtime не нужны.

Desktop 518, protocol 139 (включая dist-копии), signaling 43, API 146,

бота и сброс при открытии, уведомление вне запомненного служебного чата.

две пересылки в «Избранное» в порядке 2/3, сортировка, отсутствие нового skeleton
и сохранение узла аватара, мобильное окно без выхода за границы.

AccountSidebar приложения не заменялась.
