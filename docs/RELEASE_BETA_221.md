## Состав

В общий выпуск входят накопленные доработки beta.206–221: покер на восемь мест,
режимы, боты/тренировки без статистики, таймеры, перерывы, звуки и плавная раздача;
Монополия с московскими улицами, карточками и общими бросками кубиков; исправления
переключения игр, интерфейса планшета, чатов, уведомлений и пересылки.

Добавлены светлая и чёрная темы с локальным сохранением, отдельно включаемой
синхронизацией между устройствами и постоянно тёмным экраном входа.
Быстрый выбор качества демонстрации доступен в окне выбора источника.
Автозапуск и автообновление включены у новых профилей; прежний выбор существующих
пользователей сохраняется.

Последние изменения: typing с плавным появлением/TTL на семи языках, просмотры
со счётчиком и аватарками в группах и простой статус в ЛС, исправление рамки
Escape. Временный чат комнаты получил маленькое меню reply/edit/copy/delete,
без закрепления, выделения и просмотров. Реакции под пузырём: свои справа,
чужие слева, зазор 3px, без движения при наведении.

Для совместного набора/просмотров участникам нужна новая версия; исторические
прочтения не восстанавливаются. Покер использует только виртуальные фишки.

## Проверки

Локальный полный `pnpm check` прошёл: desktop542/API155/protocol139/signaling46/
Cloudflare15/admin2. В браузере проверены 1440×950 и 390×844, компактное меню,
чтения группы/статус ЛС, Escape и границы реакций до/после hover. Прочтения
пишутся после видимости в активном окне; повтор не меняет первую дату.

API beta.54/schema031 и signaling0.1.20 установлены при activeRooms=0 с проверкой
владения, backup/rollback и живым тестом двух аккаунтов/двух клиентов; резерв
побайтово совпал, схема реплицирована, HA healthy. При публикации веба и пакетов
повторных перезапусков API/сигналинга не требуется.

## Публикация

Выпуск опубликован 08.11.2026. GitHub Actions `42498462153` успешно завершил
общие проверки, Windows x64, macOS ARM и подготовку выпуска. Публичный релиз
не draft, не prerelease, установлен latest. Подписи обоих updater-пакетов
локально проверены по прежнему открытому ключу TRLKA; manifest содержит ровно
