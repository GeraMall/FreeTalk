## Состав

В общем планшете доступны шахматы, сапёр, морской бой, Монополия,
«Кто хочет стать миллионером?» и покер с виртуальными фишками. Новые игры
получили лобби и места игроков. Шахматы поддерживают контроль времени,
историю ходов, ничью, сдачу и зрителей. Морской бой рассчитан на двух капитанов;
зрители видят оба поля после старта. Курсоры участников передаются отдельно
от игровых действий и скрыты в морском бое и покере.

Приватные карты и расстановки остаются на сервере. Каждому подключению
передаётся персональная проекция; места закреплены за сессией или проверенным
аккаунтом. Новые игры согласуются через `activityVersion: 2`; старые клиенты
сохраняют прежний протокол. Для совместной игры нужна beta.205.

Это первая версия новых игр. Монополия использует собственное космическое
оформление и правила, викторина — стартовый банк вопросов. Деньги и ставки
реального мира не используются. Автоматический выход/поражение при отключении
игрока пока не реализованы; ведущий может завершить или сбросить игру.

## Развёртывание

Сигналинг 0.1.10 установлен до общего выпуска и синхронизирован на резерв.
Его единственный перезапуск во время текущего звонка был отдельно разрешён
владельцем; восстановление исходной комнаты с тремя участниками подтверждено.
При публикации веба и пакетов службы звонков повторно не перезапускались.

Веб-файлы опубликованы атомарной заменой index.html с сохранением прежних
хешированных assets. Проверены побайтовое совпадение публичных JS/CSS и
одинаковый index.html на основном и резервном узлах. PostgreSQL streaming,
синхронная репликация без отставания; проверки обоих узлов проходят.

GitHub Actions успешно завершил общие проверки, Windows-сборку и macOS ARM-сборку.
Для macOS отдельно проверен `/usr/lib/swift` LC_RPATH; запуск на физическом Mac
в рамках выпуска не выполнялся. Подписи установщика Windows и updater-архива
macOS локально проверены по открытому ключу TRLKA. Публичный latest.json
совпадает с проверенным manifest и содержит обе платформы; оба файла доступны
с ожидаемыми размерами.

## Исправление скачивания с сайта

8 ноября исправлены три кнопки скачивания на главной странице. Замена версии
в предыдущем сценарии меняла папку релиза на beta.205, но оставляла beta.200
в имени EXE: граница `\b` не совпадала с подчёркиванием после номера. GitHub
возвращал 404. Ссылки заменены целиком без изменения дизайна и синхронизированы
на резерв. Добавлена обязательная проверка `scripts/release/verify-download-links.mjs`,
которая сверяет папку и имя установщика, выполняет HEAD и отклоняет HTML-ответы.
В браузере нажатие основной кнопки скачало EXE beta.205, сохранив страницу TRLKA
открытой. SHA256 скачанного файла совпал с проверенным пакетом выпуска.
