# TRLKA beta.224

08.11.2026 владелец явно разрешил общий выпуск для Mac и Windows, отдельно
уточнив: Windows меняет только номер версии. Веб-приложение, API, сигналинг и
Android APK в эту публикацию не входят. Сайт получает только новые ссылки
скачивания; службы звонков не перезапускаются.

## Раздельные исходники

- Mac Apple Silicon: `4ca2613`, проверенный подписанный пакет из
  [CI42510597827](https://github.com/GeraMall/FreeTalk/actions/runs/42510597827).
  Подробности: `MAC_SCREEN_CAPTURE_BETA224.md`.
- Windows x64: `11faca7`, ветка `release/windows-version-beta224`, родитель —
  публичный тег223/`32893df`. Diff содержит только5замен223→224 в файлах версий.
  [CI42514068028](https://github.com/GeraMall/FreeTalk/actions/runs/42514068028)
  выполняет полныйcheck, nativecheck и подписанную updater-сборку.

Неподписанный Windows-пакет из preview CI42510597827 не публиковать.
Mac-пакет повторно не собирается: используется уже проверенный артефакт4ca2613.
Тег224 исключён из автоматической пересборки/публикации workflow, чтобы новый
job не заменил специально подготовленный Windows version-only пакет.

## Содержание и ограничения

В актуальном логе Mac223 все707замеров начинались с capture640×414, уже до
кодирования. Mac224 отдельно запрашивает размер выбранного источника через
applyConstraints, учитывая его возможности/пропорции. Есть ограниченные по
времени попытки настройки и дополнительная диагностика. Новый профиль Mac:
text/1080p/30FPS; существующие ручные настройки сохраняются, профиль можно
применить кнопкой. Политика Windows не меняется.

Физического Mac для подтверждения результата здесь нет. Повторное чёрное
превью/системный звук на Mac не объявляются исправленными. Владелец разрешил
общую публикацию, зная, что результат новой правки пока требует проверки друга.

План публикации: проверить обе updater-подписи существующим ключом, собрать
manifest ровно для windows-x86_64/darwin-aarch64, загрузить в draft, затем
опубликовать latest. Атомарно заменить два статических файла на основном VPS
(landing/latest), выполнить export/sync и проверить резерв, настоящие ссылки
скачивания и неизменностьPID API/сигналинга. Итоговые хеши записываются после
завершения проверок.
