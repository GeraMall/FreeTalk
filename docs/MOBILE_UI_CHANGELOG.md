# Журнал мобильных изменений TRLKA

## 0.2.1 build 8 — 2 ноября 2026

- Акцент `#8da6dc`, фон `#020914`; семантический online и включённый микрофон — зелёные. По уточнению владельца плотная зелёная заливка микрофона заменена полупрозрачной: opacity 0.16, зелёные иконка/подпись, обводка opacity 0.38. Аватар имеет непрозрачную основу и не пропускает обложку профиля.
- Голосовой звонок показывает компактный список. Появление камеры или демонстрации переводит представление в видеосетку, выключение последнего видео возвращает список через 550 мс. При этом WebRTC, звук и захват не перезапускаются.
- `CallTileLayout` делит доступную площадь поровну между 1–8 карточками, без пустой ячейки при нечётном количестве. В коротком горизонтальном окне разрешается вертикальная прокрутка, чтобы сохранить минимальный размер. Для Android переносить расчёт площади и выбор рядов, а не фиксированное число колонок.
- Нажатие разворачивает участника. Кнопка возвращает сетку. Если своя камера включена, мини-превью находится сверху: перетаскивание ограничено областью видео, pinch меняет ширину в пределах 96–240 pt (дополнительно ограничена экраном), tap меняет большое и малое изображение местами. При повороте экрана позиция сбрасывается в видимую область.
- Переходы используют короткую пружинную анимацию, Reduce Motion отключает её. Четыре отдельные кнопки в одном ряду: общая ширина до 300 pt, высота 54 pt, отступ 8 pt, без общего «острова». Область нажатия остаётся больше 44 pt.
- Для Android: хранить list/grid/focused как состояние представления отдельно от call service; использовать тот же debounce, непрозрачные аватары, ограничения PiP и семантические цвета. Возврат к списку и изменение размеров не должны менять SDP/звуковые дорожки.

Собственная камера отделена от источника screen, чтобы локальное зеркало работало и в карточке, и в мини-превью.
Исходники логики звонка: `2af79b1`, мягкой кнопки микрофона: `10323c6`. IPA: 0.2.1 (8), arm64, iOS 17+, bundle ID `com.trlka.ios`, SHA-256 `7a864e7c692abc7392acb9206366f4d91eb3e597a4287170625fd2fdc8cc7ad6` (IPA run `41430172106`, проверен после скачивания). Проверенный предыдущий build 7: SHA-256 `0bad7f334b4cbcdbaa085bafbf6e85e0af5a97fbd7df96de5d2b854e8d29298b`.
Проверки: равная площадь и границы для 1–8 участников на телефоне/планшете; UI-сценарий переключения списка/сетки, разворота, смены мест, pinch и перетаскивания. Синтетическая камера существует только в Debug. Проверка IPA подтверждает отсутствие debug fixtures; настоящий звук, камера и Bluetooth требуют устройства.

## Как проверяется

Дополнительно: черновик сохраняется в памяти по chatId при переходах внутри
приложения и очищается при logout. Карточки ожидающих адресатов вызова отделены
от подключённых участников и удаляются при подключении, отказе или пропущенном
приглашении, включая срок expiresAt из ответа сервера при потере realtime-события.
Профиль, назад, звонок, отправка и основные действия имеют область нажатия не
меньше 44 pt. Android должен повторять эти состояния, не показывая фиктивный online.

1. Core tests проверяют сохранение сессии, восстановление после сети, форматы
   комнат/приглашений и адреса транспорта.
2. Native media test создаёт реальные PeerConnection и проверяет glare,
   декодирование синтетического видео и повторное включение дорожки.
3. UI tests нажимают вкладки, открывают переписку/настройки, вводят текст,
   сворачивают звонок, возвращаются к нему из чата и завершают его.
4. Debug-снимки главной, чатов, переписки, свёрнутого/полного звонка, настроек,
   друзей и истории проверяются на iPhone и iPad. Fixtures отсутствуют в Release.
5. IPA проверяется как arm64 iPhoneOS с нативным WebRTC, privacy descriptions,
   audio background mode, лицензиями и без ключей подписи/debug fixtures.

Результаты проверок и SHA-256 сохраняются вместе с выдаваемой тестовой IPA.
Это не заменяет проверку звука, Bluetooth и блокировки экрана на настоящем iPhone.
Входящие в закрытом приложении, APNs/CallKit, передача экрана с телефона, вложения
и дополнительные действия над чатами ещё не объявлены готовыми.
