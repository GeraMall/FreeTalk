# TRLKA beta.194

Владелец разрешил общий выпуск 05.11.2026 после проверки Windows-предпросмотра 3.
Платформы выпуска: Windows x64, macOS Apple Silicon и веб-приложение.

## Изменения

- Повторное нажатие на открытый раздел больше не перезапускает загрузку. Недавно открытые друзья, история и чаты показываются из ограниченного кэша текущего входа.
- Убраны вспышка приветствия бота, повторные анимации существующих реакций и подёргивание фотографий при переключении чатов. Новые уведомления бота продолжают обновляться.
- Исправлено падение Windows при создании вспомогательных окон WebView2. Внутренние окна используют одинаковые параметры профиля.
- Соединение аккаунта на настольных платформах использует нативный WebSocket, чтобы сворачивание окна не останавливало ответы серверу. Автоматический статус «отошёл» и ручные статусы сохранены.
- Обновлены окно пересылки, кнопка сброса настроек, круглая аватарка бота и компактная панель возврата к последним сообщениям.
- Экран входа адаптирован к небольшим окнам; на телефонах QR-блок не создаётся. В компактной настольной компоновке вкладки стали тоньше, глазик пароля выровнен.
- Аватарки, названия и подписи в списке чатов слегка увеличены.
- Устранены повторный запуск проверки/загрузки обновления и лишние перерисовки прогресса.

## Проверка и границы

Автоматические проверки дополнены браузерной проверкой быстрых переходов, фотографий,
уведомлений бота и восьми размеров экрана входа. Исправленный Windows-клиент запущен
с существующим профилем. Сборка macOS проверяется CI; проверка на реальном Mac и
непрерывная проверка фонового статуса с двумя реальными устройствами остаются отдельными
проверками и не заявляются как выполненные.

Исходники API и сигналинга в этом выпуске не меняются. Обновление веб-файлов не требует
перезапуска сервера звонков. Нативные iOS/Android-приложения в этот выпуск не входят.
