# TRLKA beta.200

06.11.2026 владелец явно разрешил общий выпуск после Windows-предпросмотра beta.200. Платформы: Windows x64, macOS Apple Silicon и веб. Mac Intel, Android и iOS в этот выпуск не входят.

Включены все десять правок из `NOV06_REVIEW_CHECKLIST.md`, исправления beta.198–199 и уточнения перед выпуском:

- Приглашение в общий планшет использует размеры обычной карточки участника. При закрытии или завершении планшета восстанавливается видимость чата до его открытия.
- После скачивания файла стрелка заменяется галочкой; повторный клик запускает скачивание заново. Отметка сохраняется при переключении чатов в текущем запуске приложения.
- Обычные уведомления сами плавно исчезают через 4,5 секунды. Ошибки, требующие внимания, по-прежнему можно закрыть вручную.
- Общий космический планшет с шахматами, сапёром и морским боем открыт всем зарегистрированным пользователям. Доступ к магазину не расширяется.
- YouTube/Rutube используют официальные интерфейсы плееров и отдельную нижнюю панель перемотки. Общий Google-аккаунт или привязка личных аккаунтов не добавляются. Ограничения самих видеосервисов сохраняются.

Серверная часть: API `0.4.0-beta.49`, signaling `0.1.9`. Публикация сервера выполняется с проверкой отсутствия активных комнат, резервными копиями и репетицией API. CSP сайта дополняется только доменами официальных видеоплееров/SDK. Общий релиз остаётся черновиком до проверки подписей и готовности серверов.

Результаты проверок и публикации будут добавлены после завершения.
