# TRLKA beta.200

06.11.2026 владелец явно разрешил общий выпуск после Windows-предпросмотра beta.200. Платформы: Windows x64, macOS Apple Silicon и веб. Mac Intel, Android и iOS в этот выпуск не входят.

Включены все десять правок из `NOV06_REVIEW_CHECKLIST.md`, исправления beta.198–199 и уточнения перед выпуском:

- Приглашение в общий планшет использует размеры обычной карточки участника. При закрытии или завершении планшета восстанавливается видимость чата до его открытия.
- После скачивания файла стрелка заменяется галочкой; повторный клик запускает скачивание заново. Отметка сохраняется при переключении чатов в текущем запуске приложения.
- Обычные уведомления сами плавно исчезают через 4,5 секунды. Ошибки, требующие внимания, по-прежнему можно закрыть вручную.
- Общий космический планшет с шахматами, сапёром и морским боем открыт всем зарегистрированным пользователям. Доступ к магазину не расширяется.
- YouTube/Rutube используют официальные интерфейсы плееров и отдельную нижнюю панель перемотки. Общий Google-аккаунт или привязка личных аккаунтов не добавляются. Ограничения самих видеосервисов сохраняются.

Серверная часть: API `0.4.0-beta.49`, signaling `0.1.9`. Публикация сервера выполняется с проверкой отсутствия активных комнат, резервными копиями и репетицией API. CSP сайта дополняется только доменами официальных видеоплееров/SDK. Общий релиз остаётся черновиком до проверки подписей и готовности серверов.

## Результат публикации

- Тег `v0.4.0-beta.200`, исходный коммит `12385d8`; CI `42216075772`: Windows, macOS arm64 и публикация успешно завершены. Релиз опубликован 06.11.2026 в 15:25 по Москве.
- `pnpm check`: форматирование, lint, типы, 637 тестов и production-сборки прошли. Размер приглашения проверен на четырёх разрешениях; восстановление чата и повторное скачивание покрыты отдельными тестами. Нативные изменения плеера ранее прошли 9 release-тестов; CI заново проверил и собрал обе платформы.
- Windows и Mac updater-пакеты проверены открытым ключом приложения. Mac-пакет содержит приложение версии `0.4.0-beta.200`, Mach-O arm64 и путь Swift runtime. Фактическая работа нового плеера на физическом Mac в этой сессии не проверялась.
- Публичный `latest.json` совпадает с проверенным манифестом и содержит Windows x64 и darwin arm64. Все восемь файлов релиза доступны по HTTP 200 с правильными размерами.
- API обновлён до `0.4.0-beta.49` после репетиции на локальном порту 8791; signaling — до `0.1.9`. Непосредственно перед перезапусками активных комнат не было. После обновления службы активны, перезапусков по сбою нет.
- На двух временных обычных аккаунтах с `can_access_store=false` через публичный WSS проверены запуск планшета, приглашение, выбор шахмат и синхронный ход e2–e4. Через защищённый публичный API проверена карточка FunPay. Тестовые аккаунты, сессии и звонок удалены; данные реальных пользователей для проверки не использовались.
- Публичные HTML, JS, CSS и service worker на `https://trlka.com/app/` совпадают с локальной сборкой. Браузерная проверка экрана входа: без ошибок JavaScript и горизонтальной прокрутки. CSP разрешает только необходимые домены официальных видеоплееров/SDK. Главная страница получила девять обновлённых ссылок/упоминаний beta.200.
- На текущем сетевом маршруте VPS YouTube oEmbed и обложка в smoke-проверке были недоступны: остаётся базовая карточка YouTube. Встроенное видео загружается отдельно устройством пользователя; ограничения и запросы входа со стороны YouTube не отменяются.
