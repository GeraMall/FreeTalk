## Что важно при проверке

Это локальный предпросмотр. Подготовлены изменения API и Node/Cloudflare signaling, но рабочий сервер, сайт, общий канал обновлений и Mac-сборка не публиковались. Полный общий доступ к планшету, приглашения обычным аккаунтам и карточки произвольных сайтов требуют этого серверного обновления при общем выпуске. Со старым сервером часть новых функций ещё недоступна.

YouTube сам управляет возрастными, региональными и антибот-проверками. В тестовом Chromium сервис запросил подтверждение входом. Наш контейнер и команды управления проверены; обещания воспроизведения любого ролика без Google-аккаунта нет. Новый плеер на настоящем Mac не проверялся. Официальные API: [YouTube IFrame](https://developers.google.com/youtube/iframe_api_reference), [идентификация приложения](https://developers.google.com/youtube/terms/required-minimum-functionality#embedded-player-api-client-identity), [Rutube embed](https://rutube.ru/info/embed/).

Сохранены изменения beta.198–199. Исправление обратной передачи голосов при демонстрации всего экрана включено; повторная проверка пользовательского эха в живом звонке не выполнялась.
