# Предпросмотр beta.209: режимы покера, боты и возраст

8 ноября 2026. Ветка `preview/poker-modes-bots-beta209`, исходники `041ec52`.
Приватный Windows-предпросмотр; публичный клиент, сайт и автообновление остаются
beta.205. Общий выпуск нового дизайна требует проверки владельцем.

## Покер

- Карты сохраняют DOM и начальную анимацию между ставками. Снимки ставок
  не запускают повторное появление или исчезновение карт.
- Постоянная колода рядом с бордом. Флоп открывается по одной карте с шагом
  520 мс, вылет занимает 650 мс. Тёрн и ривер приходят из колоды после торгов.
  Полные 30 секунд на решение начинаются только после открытия борда.
  При ALL IN итог, чужие комбинации и выплата ждут окончания открытия борда.
- Нижняя панель в обычном потоке страницы не накрывает свои карты. На коротких
  экранах доступна вертикальная прокрутка, горизонтального переполнения нет.
- «Пас» красная со светлым текстом; на зелёной кнопке ставки текст чёрный.
  Белая цифра места — в дуге правого верхнего угла карточки. BB — красная фишка,
  SB — синяя; по нажатию объясняется обязательная ставка и сумма. На телефоне
  фишки отделены от цифр и карт. Боковой акцент повторяет скругление карточки.
  Мягкий белый свет текущего хода и золотой таймер остаются отдельными.
- До старта: обычный стол с тремя докупками по 1000; турнир с удвоением блайндов
  каждые 15 минут; турнир с постоянными блайндами. В турнирах нет докупок.
  Новый уровень применяется со следующей раздачи. Анте включается отдельно:
  10% большого блайнда с каждого в банк до блайндов, без зачёта как колл.

## Тренировка и смена игры

Боты доступны организатору в шахматах, морском бое, монополии и покере.
Это ограниченные эвристики, без внешнего AI и обращений к базе на ходах.
Морской бот не читает чужую скрытую расстановку, покерный использует только
свою руку и общий борд. Сапёр и викторина остаются одиночными или совместными.

После хотя бы одного бота весь текущий стол тренировочный, включая игру с
друзьями. Статистика не записывается. Удаление бота или сброс того же стола
не снимает отметку. Для будущей статистики есть `tableCountsForStatistics`.

Любой новый клиент может вернуться в каталог и предложить другую игру.
Угловой блок со звуком предлагает перейти либо остаться. Решение принимает
большинство фиксированного состава новых клиентов, срок 20 секунд, повторное
предложение не чаще 30 секунд. Крестик только скрывает окно у себя. Предыдущая
игра заменяется после большинства, новым организатором становится инициатор.
Истечение времени, отказ или уход инициатора сохраняют предыдущую игру.

## Дата рождения и 18+

API вычисляет допуск по дате в базе; клиентский флаг не считается доверенным.
До 18 лет, гостям и без даты закрыты покер и просмотр, включая приватные руки.
Звонок и остальные игры доступны. Организатор подтверждает 18+ перед стартом,
сервер отдельно проверяет всех людей за столом.

При первом авторизованном использовании аккаунт без даты получает личное
сообщение бота. Проверка также есть при открытии бота. Уникальный ключ исключает
дубли. ДД.ММ.ГГГГ проверяется на календарь, будущее и нижнюю границу 1900 года.
Обновляется только свой профиль и только NULL-дата. Сохранённую дату нельзя
переписать сообщением; для исправления — поддержка. Дата не уходит как баг/идея
по почте, даже при начатом обращении. Доступ обновляется кнопкой планшета.

Дата заявляется пользователем без проверки документа. Галочка 18+ не является
юридическим разрешением азартных игр. Только виртуальные фишки: без покупок,
вывода денег, денежных ставок и призов.

## Проверки

Полный `pnpm check`: format, lint, типы, сборки и тесты. Protocol 82,
signaling 39, API 145, desktop 469, Cloudflare signaling 15, admin 2 — успешно.
Журнал: `outputs/doc-review/poker209-check.log`. После уточнения меток блайндов
пройдены desktop typecheck, lint, форматирование и 12 затронутых тестов;
итоговый интерфейс собран упаковщиком Windows.

Браузер: 1440×1000, 1024×768, 850×800, 390×844, 320×667, 430×932. Пересечений
карт с чужими карточками и нижней панелью нет. На 390×844 видны восемь игроков
и действия, на 320×667 используется прокрутка. Проверены восемь цифр места,
метки, подсказка по нажатию и Escape. Артефакты: `output/playwright/poker209-*`.
Это размеры браузера, не испытание на физических телефонах или восьми камерах.

Четыре локальных WebSocket-клиента и серверный бот: рассадка, анте, подтверждение
возраста, раздача, ход бота, флоп, стабильные узлы карт после ставки, отсутствие
статистики. Голосование неорганизатора переключило четверых на шахматы после
трёх голосов, новый организатор верен.

Проверка рабочего API с тремя временными QA-аккаунтами: напоминание только без
даты и один раз; невозможная дата отклоняется; правильная сохраняется только
владельцу; повторное изменение отклоняется; возраст вычисляется верно; дата
не раскрывается внутреннему профилю и не создаёт почтовое обращение.
QA-аккаунты удалены. Журнал: `outputs/doc-review/poker209-birthday-integration.log`.

## Сервер и совместимость

API beta.51 установлен перед signaling 0.1.14, без миграций и новых зависимостей.
Изменены три модуля API и версия манифеста, сохранены файлы отката. Перед каждым
перезапуском проверено `activeRooms: 0`. Обе версии подтверждены основным сервером;
файлы побайтово совпали на резерве, монитор вернул `TRLKA_HA_HEALTH_OK role=reserve`.
Журнал: `outputs/doc-review/poker209-server-deploy.log`.

Клиенты согласуют `tabletVersion: 3`, столы имеют `edition: 3`. Новый стол не
отправляется старому клиенту. Для общей проверки нужен beta.209 у всех участников.
Старые взрослые столы сохраняют прежние правила; запрет по возрасту действует
и для старых пакетов. Клиент не может присвоить UUID бота для получения его руки.
