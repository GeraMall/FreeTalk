# TRLKA 0.4.0-beta.176

- Доработана панель профиля: согласованные размеры текста и отступы, длинные имена аккуратно сокращаются.
- Увеличены кнопки микрофона и наушников; улучшены состояния выключенного звука и меню устройств.
- Убрано вращение шестерёнки настроек. Меню устройств закрывается по Escape, смене фокуса и нажатию снаружи.
- Сохранённый вход больше не удаляется при временном сбое сети/сервера. Есть повторная попытка; зависшее восстановление ограничено по времени.
- Исправлен сбой создания веб-звонка при мгновенном восстановлении страницы. Возврат на вкладку сохраняет здоровое соединение; повторное подключение до подтверждения создания не превращается в вход в отсутствующую комнату.
- Исправлен повторный вход в разговор после восьми минут: таймер ожидания действует только для создателя ещё не принятого вызова и не закрывает подключение во время обмена списком участников.
- В узком окне профиль собеседника не сжимает переписку и открывается поверх неё.
- После восстановления подписки чат сверяет карточки звонков с сервером: пропущенное завершение вызова больше не оставляет старую кнопку подключения. Черновик и загруженная история сохраняются.

Сохранены прежний стиль TRLKA и нативная демонстрация экрана Windows. Редизайн через unslop в этот выпуск не входит.

Одновременно на сервере восстановлена выдача резервных TURN-соединений и добавлено завершение карточек неудавшегося вызова, для которого комната ещё не успела создаться.
