# Mobile chat preview beta.182 — 02.11.2026

Пользователь попросил выровнять аватар и сообщение по верхнему краю,
сделать плашки немного компактнее и исправить исчезающую верхушку чата бота.
Новый дизайн передаётся отдельной Windows-сборкой, рабочий канал остаётся beta.181.

- `.message-bubble-row`: `align-items: flex-start`, включая компактный режим;
  чат комнаты — `align-items: start`. Сам стек сообщений и реакции остаются вместе.
- Плашки: отступы 10×13px вместо 13×16px; максимум стека 70%/640px на ПК,
  84% на телефоне. У бота аналогично уменьшены отступы.
- Заголовок бота учитывает `env(safe-area-inset-top)`, как обычный мобильный чат;
  стрелка возврата имеет собственную несжимаемую ячейку.
- `installMobileViewport` подстраивает мобильную оболочку под `visualViewport`
  при открытой клавиатуре, восстанавливает начало окна после её закрытия.
  Обработчик не отменяет touch-события и не запрещает вертикальный скролл сообщений.

Проверки браузером: 1366×900, 820×1180, 390×844. Разница верхних координат
аватара и плашки для входящего/исходящего сообщения — 0px на каждом размере.
Мобильный сценарий использовал iPhone User-Agent и признак standalone:
фокус ввода, сжатие visual viewport до 520px со смещением 100px, закрытие
клавиатуры и возврат из бота/обычного чата. Пройдены главная, друзья, история,
чаты и 7 разделов настроек; горизонтального переполнения и pageerror не было.
Данные API и входа подменены; реальные аккаунты/письма не использовались.
Есть отдельный тест восстановления viewport; физический Safari не проверялся.

Отдельный HTTPS-предпросмотр: https://trlka.com/preview/chat182/.
Он не заменяет `/app/` и основной сайт. Все ресурсы имеют относительные пути;
предпросмотр предназначен для открытия в браузере, не для установки PWA.

## Эталон для iPhone/будущего Android

- Холст чата `#07111d`, входящие `#101e2e`, исходящие `#1a2c48`, ввод `#050d18`,
  заголовок `#0a1623`, граница `#29384e`, акцент `#8da6dc` → `#4b7fff`.
- Аватар сверху, отдельные входящие слева / исходящие справа, сгруппированные
  сообщения сохраняют отступ без повторного аватара.
- Скругление 14px с плоским верхним углом со стороны аватара; размер ввода
  и отправки на телефоне 44px, текст ввода 16px, без подсказки под ним.
- Корневая навигация внизу; в открытом чате — собственный заголовок со стрелкой.
  Без горизонтального перемещения страницы, скролл только внутри списка/экрана.
- Экран живого звонка и его медиалогика не входят в перенос дизайна iPhone.

Нативная реализация подготовлена в commit `158a03d` и доработана в `4b63709`
ветки `preview/apple-web-style-030-build10`:
`WebTheme.swift`, `MessageLine.swift`, `ServiceBotScreen.swift`,
`PeerProfileScreen.swift` и существующие экраны. SwiftUI safe areas используются
вместо ручного позиционирования по высоте строки состояния.
