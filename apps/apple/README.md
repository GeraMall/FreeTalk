# TRLKA для iPhone, iPad и Mac

Новый нативный проект SwiftUI, отдельный от Windows/Tauri и веб-интерфейса.
Минимальные версии: iOS/iPadOS 17 и macOS 14. Это **предварительная разработка,
не готовый релиз**. Текущие Windows, Android и сайт не изменяются.

## Что реализовано в первом срезе

- Две цели приложения: iPhone/iPad и Mac (Apple Silicon + Intel), одна библиотека сетевых моделей.
- Вход через существующий API TRLKA, восстановление входа, выход.
- Refresh token в системном Keychain с `ThisDeviceOnly`; access token только
  в памяти. При потере сети сохранённая сессия остаётся для повторного входа.
- Список существующих чатов, поиск, чтение, отправка текста и загрузка истории.
- Пока обновление выполняется опросом только в активном приложении: список
  раз в 8 секунд, открытый чат раз в 4 секунды. Это не realtime и не push.
- Нативные прокрутка, навигация и адаптация split view под iPad/Mac.
- Профиль, запрос письма восстановления пароля, переключатель видимости пароля.
- Сборки симулятора и устройства без подписи, Mac preview и снимки iPhone/iPad
  через `.github/workflows/apple-native.yml`.

## Запуск на Mac

Нужны полный Xcode с iOS Simulator SDK, выбранный через `xcode-select`, и XcodeGen.

```sh
brew install xcodegen
cd apps/apple
swift test --package-path Packages/TRLKACore
bash script/build_and_run.sh macos --verify
```

Для iPhone/iPad-симулятора выберите конкретный UDID:

```sh
xcrun simctl list devices available
SIMULATOR_UDID='<UDID>' bash script/build_and_run.sh ios
```

Скрипт Mac поддерживает `--build-only`, `--verify`, `--logs`, `--debug`.
В папке `apps/apple` есть локальная Run action для macOS.
Проект Xcode генерируется из `project.yml` и не хранится в Git.

Для настоящего устройства откройте сгенерированный `TRLKA.xcodeproj`, выберите
TRLKA-iOS, свою Team и подключённое устройство. Платная подписка не является
условием сборки симулятора. Подписанные IPA/TestFlight-архивы здесь пока не создаются.
Mac preview имеет локальную ad-hoc подпись, **не нотарифицирован**, не подходит
для общей раздачи. Не отключайте Gatekeeper ради запуска.

Адрес API берётся из build setting `TRLKA_API_BASE_URL`. Сейчас это действующий
`https://freetalk.191-44-38-60.sslip.io/api`, как в Windows beta. На момент проверки
1 ноября 2026 `/api/health` возвращал API beta.38, а `https://trlka.com/api/health`
возвращал 404. Переход на `https://trlka.com/api` выполняется после настройки и
проверки резервируемого входа из `docs/SERVER_POOL.md`; одного изменения адреса
в клиенте для переключения серверов недостаточно. Секретов в этом параметре нет.

## IPA для установки через Windows

`bash script/build_ipa.sh` на Mac собирает Release для настоящего iPhone/iPad
(arm64, iOS 17+) и создаёт `build/TRLKA-0.1.0-iOS-unsigned.ipa`.
Подписка разработчика и сертификаты для **сборки этого файла** не используются.
Отдельный workflow `.github/workflows/apple-ipa.yml` делает то же в облаке.
`script/verify_ipa.py` проверяет структуру Payload, платформу и архитектуру Mach-O,
права исполняемого файла, метаданные, отсутствие шифрования и секретных ключей,
контрольные суммы ZIP и SHA-256. Проверка упаковки не подтверждает установку на устройство.

Для установки нужен Windows-компьютер, кабель и личная подпись:

1. Скачайте [Sideloadly с официального сайта](https://sideloadly.io/).
   Установите зависимости iTunes/iCloud по инструкции этого сайта.
2. Подключите и разблокируйте iPhone. Подтвердите доверие компьютеру.
3. Откройте Sideloadly, выберите iPhone и перетащите `.ipa` в окно программы.
4. Укажите свой Apple Account и нажмите Start. Пароль и код подтверждения вводите
   только самостоятельно в установщике, не отправляйте в чат.
5. При запросе iOS подтвердите профиль разработчика в «Настройки → Основные →
   VPN и управление устройством» и включите «Режим разработчика» в разделе
   «Конфиденциальность и безопасность».

По [FAQ Sideloadly](https://sideloadly.io/faq), бесплатная подпись действует 7 дней;
затем её требуется обновить. Этот IPA не устанавливается простым нажатием в Safari
и не предназначен для TestFlight/App Store. Реальную установку, подпись своим
аккаунтом и запуск на вашем iPhone ещё нужно проверить.

В приложении пока проверяются вход и текстовые чаты. Звонки, камера, демонстрация,
push-уведомления и вложения не подключены. При `CAPTCHA_REQUIRED` вход пока
блокируется, ограничения сервера не обходятся.

## Условия до публичного выпуска

Сначала рабочая beta через TestFlight, затем App Store после проверки Apple.
Покупка Apple Developer сама по себе не означает готовность приложения или
гарантированную дату публикации.

1. Нативный WebRTC со сверкой протокола Windows/Android/web: личные и групповые
   звонки, переподключение после смены сети и отказа узла; камера и локальное
   зеркалирование только предпросмотра.
2. iOS AVAudioSession, CallKit, обычные APNs и VoIP PushKit **только для звонков**;
   хранение APNs-токенов и отправка на сервере. Проверить реальные фоновые входящие,
   заблокированный экран, Bluetooth, отключение разрешений, смену сети.
   Нельзя подменять фоновые звонки бесконечным таймером или фиктивным аудио.
3. Mac: ScreenCaptureKit, системный звук, разрешения, повторный старт демонстрации;
   iOS: отдельная ReplayKit broadcast extension и проверка политики распространения.
4. Подключить серверную CAPTCHA безопасным разрешённым потоком. Сейчас при
   `CAPTCHA_REQUIRED` вход останавливается: защита сервера не отключается.
5. Полные нативные регистрация, подтверждение почты и завершение сброса пароля;
   удаление аккаунта, жалобы и блокировка пользователей. Проверить существующие
   серверные возможности, не обещать неподключённые функции.
6. Фото/файлы, realtime-события и обновление удалённых/изменённых сообщений.
   Сейчас вложения представлены только текстовым описанием, их открытие не реализовано.
7. Реальные устройства: iPhone и iPad, маленький экран, поворот, Dynamic Type,
   VoiceOver, клавиатура, продолжительный разговор, повторное включение захвата
   со звуком. Не считать успешную компиляцию доказательством качества связи.
8. Проверить иконки и launch screen; заполнить App Privacy, политику
   конфиденциальности, поддержку, возрастной рейтинг, экспортную декларацию,
   reviewer credentials. Privacy manifest формируется по реально используемым API
   и SDK; не добавлять выдуманные причины доступа.
9. После активации подписки зарегистрировать bundle IDs `com.trlka.ios` и
   `com.trlka.macos` (сначала проверить доступность), настроить Team, provisioning,
   APNs, сертификаты и безопасное хранение ключей вне Git.
10. Подготовить подписанные archives и экспорт, TestFlight, проверку review,
    для прямой раздачи Mac отдельно Developer ID + notarization + stapling.

Ближайший этап после этого среза — native media и сквозной тест звонка с Windows.
На текущем этапе нет ни фоновых звонков, ни функции «поверх всех приложений».

Официальные требования:

- [TestFlight](https://developer.apple.com/help/app-store-connect/test-a-beta-version/testflight-overview/)
- [App Review Guidelines](https://developer.apple.com/app-store/review/guidelines/)
- [Удаление аккаунта](https://developer.apple.com/support/offering-account-deletion-in-your-app/)
